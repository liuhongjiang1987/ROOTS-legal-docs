## 反馈与建议

请在本仓库 **[Issues](https://github.com/liuhongjiang1987/ROOTS-legal-docs/issues)** 提交，并选择合适模板：

| 模板 | 适用场景 |
|------|----------|
| **缺陷报告** | 扩展 Bug、无法划词、侧栏异常、登录失败等 |
| **功能建议** | 新功能或体验改进想法 |
| **词条与拆词反馈** | 某个单词的拆词、词源、同根词、释义问题 |

提交前请尽量填写 **扩展版本号**（当前商店版可在 `chrome://extensions` 查看）。
